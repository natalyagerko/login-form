Практическое задание: CSS и верстка

Описание проекта

Проект представляет собой веб-страницу авторизации, созданную с использованием HTML и CSS.

Цель работы — освоить базовую HTML-разметку, научиться стилизовать элементы страницы и создавать форму авторизации в соответствии с представленным макетом.

Используемые технологии

- HTML5
- CSS3
- Google Fonts (Raleway)

Структура проекта

- index.html — HTML-разметка страницы.
- index.css — таблица стилей.
- images.rar — папка с изображениями проекта.

Этапы выполнения работы

1. Подготовка рабочей среды в Visual Studio Code.
2. Создание базовой HTML-разметки страницы авторизации.
3. Стилизация страницы с помощью CSS.
4. Проверка корректности отображения страницы в браузере.

Инструкция по запуску

1. Скачать или клонировать репозиторий на компьютер.
2. Открыть папку проекта.
3. Запустить файл index.html в любом современном браузере.
4. Страница авторизации отобразится в браузере.

Результат

В результате выполнения работы создана и проверена веб-страница авторизации с использованием HTML и CSS.
